# English supplementary content review (11 October 2026)

The existing Serag OS curriculum remains the foundation. This release adds original adult-oriented explanations and exercises; the supplied PDFs are supplementary references for topic selection and progression. It does not publish publisher pages, audio, model essays, or copied exercise sets.

## Review scope

Review covers the contents/syllabuses and representative lesson, practice and review pages from every supplied file. It is a curriculum/content selection review, not a claim that every page has been transcribed or every exercise imported. Everybody Up PDFs and Scholastic Grade 1 are image scans; sample pages were rendered and OCR was checked against the page images. OCR watermarks/contact information and layout artefacts are excluded from the application.

## Release contents and limits

- 18 original lessons, each with formula, contextual examples, misconception, memory aid, application task and mini check.
- 120 original supplementary choice questions. Supplement lesson mini checks reuse their first bank question and are not double-counted in the academy queue.
- 2 new maps: sentence foundations and writing. Existing four maps remain.
- 7 original writing exercises: paragraph, paraphrase, overview, Academic table report, opinion essay, discussion essay plan and General letter.
- One-at-a-time topic practice, original-answer history, previous/next navigation with no duplicate attempt recording, and solved-question prioritisation based on due dates.
- Writing drafts and self-review checkboxes persist per account in localStorage. No automated IELTS band is claimed.
- New academy data is still local to this browser. Existing synced grammar progress remains on its existing route.
- The bank is a small static content bundle, not a newly created Supabase question table. Only one session question is rendered at a time. Source PDFs are not bundled.
