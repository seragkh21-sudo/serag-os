# Goals and shared vocabulary practice

Tasks now includes owner-scoped goal documents in Supabase `workflow_goals`. Results have explicit acceptance criteria; linked task completion and project statuses remain separate from assessed quality. One existing task can contribute to multiple tracks without duplicate counts. A revision check prevents overwriting a goal changed by another device. Suggestions are deterministic and free; only acceptance creates a task. Fictional brand briefs are labelled as speculative work.

Words and Engoplay use one sentence engine and the complete vocabulary deck (202 unique published items), plus the signed-in user's saved words. Exact examples are preferred; conjugated answers retain their natural sentence form. Twelve exceptions have curated natural examples. Unknown custom words without examples use an explicitly labelled notebook recall sentence. Hints reveal one letter, retaining spaces and punctuation. Wrong attempts, assisted corrections, and revealed answers do not count as independent first-attempt successes. Unassisted outcomes use the existing Engoplay server-sync queue and duplicate daily question guard. Detailed assisted/retry history remains owner-scoped on the current browser.

Goal document, task brief, task due date and task completion persist through existing Supabase authentication. Task links/subtasks/criteria are stored within the goal document; external file links are entered as text. No paid API, subscription, visa scoring or fabricated readiness metric is used. Existing task lists and game features remain available. Optional board/timeline views and automated assessment are intentionally outside this coherent first implementation.

Validation: sentence coverage/normalization/hints/retry/reveal/isolation tests plus goal-result semantics and existing academy, Engoplay, home, admin and video regressions. The additive schema has SELECT/INSERT/UPDATE ownership policies, no anonymous privileges and no service-role exposure. Browser flow verification uses isolated preview fixtures, not real user data.
