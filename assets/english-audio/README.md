# Published English curriculum recordings

These MP3s contain the public curriculum's words and selected example sentences, generated with Kokoro-82M q8 and the American `af_heart` voice. They contain no user recordings, uploaded articles or private account text.

Model/runtime source: https://huggingface.co/hexgrad/Kokoro-82M and https://github.com/hexgrad/kokoro . Model weights and the existing Kokoro runtime use Apache-2.0; retain their notices when redistributing those components. These are synthetic lesson recordings; no speaker impersonation or proficiency score is implied.

The catalog records text-to-file mappings. Regenerate or extend them with `scripts/generate-english-audio.mjs`; normal Vercel builds do not re-run inference. A missing recording/accent uses device speech.
