# Selected English dictionary data

`english-dictionary-v1.json` is a bounded snapshot of English Wiktionary entries retrieved through https://freedictionaryapi.com/ for public SERAG OS curriculum terms.

The data and this normalized/selected derivative are distributed under **CC BY-SA 4.0**: https://creativecommons.org/licenses/by-sa/4.0/ . Each entry retains an original Wiktionary page URL and source/license metadata. Attribution is displayed in the dictionary UI.

Changes: selected curriculum entries; retained a bounded number of senses, pronunciations and examples; converted field names to the app's existing dictionary format. This does not establish a separate license for the entire application or for audio downloaded from other sources.
